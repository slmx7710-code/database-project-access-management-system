# database-project-access-management-system
Database Project – Management System (Access / Merise)
 Project Description

This project is a university database management system developed using Microsoft Access.
It is based on the Merise methodology and focuses on the design and implementation of a relational database for managing teams, employees, and construction projects in a real estate company.

The main goal is to apply database design concepts such as conceptual modeling, relational schema design, and data integrity rules.

 Objectives
Apply the Merise methodology (data modeling approach)
Design a relational database system
Implement tables and relationships in Microsoft Access
Enforce data integrity constraints
Create forms and reports for data management
System Content
Employees
Name, Surname
Date of Birth
Recruitment Date
Main Specialty
Optional: address, phone numbers, secondary specialty
 Teams
Specialty (electricity, masonry, etc.)
Project type (residential, commercial, industrial, etc.)
Availability status
 Projects
Description
Address
Start Date
End Date
Project Type
Linked teams
 Functionalities
Add, edit, and delete employees, teams, and projects
Display filtered lists (by team, specialty, or project type)
Generate reports (employees per team, active projects, etc.)
Manage relationships between entities
 Technologies Used
Microsoft Access (Database)
Merise methodology
Relational database modeling
